Mission Demolition

Project Description

Mission Demolition is a 3D physics-based game developed in Unity. The goal is to launch projectiles from a slingshot to knock down castle structures and complete each level. The game contains four original castles that increase in difficulty as the player progresses.


How to Play

Launch the game in Unity.

Aim the slingshot toward the castle.

Launch a projectile to hit the castle and knock down its blocks.

Complete each castle to advance to the next level.

Finish all four levels to reach the Game Over screen.

Select Play Again to restart the game.


Features and Enhancements

Four Unique Castle Levels

The game includes four original castle designs. Each level increases in difficulty, providing a greater challenge as the player progresses.

Slingshot Rubber Band

A Line Renderer displays the slingshot's rubber band, making the aiming and launching process more visually engaging.

Sound Effects

Sound effects play when the slingshot launches a projectile and while the projectile is in flight. These sounds improve the game's audio feedback.

Block Impact Particle Effects

Particle effects appear when projectiles hit objects, making collisions more noticeable and adding visual feedback to the physics-based gameplay.

Game Over Screen

After the player completes all four levels, a Game Over screen appears. The Play Again button allows the player to restart the game.
